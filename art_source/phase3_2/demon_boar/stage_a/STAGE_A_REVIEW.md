## Delivered asset

- `demon_boar_stage_a.blend`: editable IK controls, three named actions, packed textures, hidden original-resolution weighted source and a visible performance derivative.
- `demon_boar_stage_a.glb`: clean runtime skeleton, skinned derivative and exactly `idle`, `walk`, `run` clips. No editor controls, studio cameras or lights exported.
- `godot_stage_a_review.zip`: isolated Godot playback/verification project. Extract outside the live game's asset tree, open `project.godot`, and run. The review scene is not gameplay integration.
- `previews/`: actual Godot recordings, three simultaneous angles per clip, still frames and skeleton overlay.
- `verification/`: measured skin, contact, export round-trip, Godot and preservation results.
- `prepare_stage_a.py`, `build_rig.py`, `refine_weights.py`, `animate_stage_a.py`, `export_stage_a.py`, `verify_skin.py`, `make_godot_reference.py`: reproducible local production steps.

The editable armature has 41 bones: 30 deformation bones, one root and ten IK/pole/hock helpers. It includes pelvis, multiple spine bones, chest, neck, head, jaw, four articulated legs, hooves, ears, three tail segments and two mane controls. Controls are editable; the runtime export contains 30 deformation joints. The high-resolution source's armature modifier is disabled for interactive performance and can be enabled for close inspection.

Skinning uses anatomical fields, surface diffusion on a position-welded weight graph and adjacent torso/limb bone-pair projection. Imported UV seams have duplicate vertices at the same physical position. Diffusing their weights independently caused visible surface tears; the graph now joins those positions while preserving the original geometry and UVs. A regression checks coincident seams at every keyed frame of idle, walk and run. This replaces initial broad automatic heat-weight transfers that caused local cross-limb and belly stretching. The final skin has no unweighted vertices, a maximum of four influences and normalized sums. Rigid soles blend into flexible ankles. Original high-source geometry, UVs and base-color pixels remain unchanged; the review derivative has repaired surface connectivity.

Scale is a provisional uniform 3 m body length, not an artistic proportion change. Blender forward is +Y; Godot forward is -Z. Floor normalization is recorded in `preparation.json`. Final encounter scale should be approved during integration.

## Verified motion

All clips loop, remain in place and use a stationary exported root. The review wrapper alone moves across the floor grid at the declared speed. Compensated stance slip is measured against that speed; playing an in-place walk on a stationary actor without matching displacement will naturally make the feet appear to slide.

| Clip | Cycle duration | Declared travel speed | Maximum planted sole height error | Maximum compensated stance slip | Godot skin matrix error |
|---|---:|---:|---:|---:|---:|
| idle | 4.0 s | 0.0 m/s | 0.0000004 m | 0.0000007 m/frame | 0.00000164 |
| walk | 1.2 s | 0.65 m/s | 0.0000606 m | 0.0000391 m/frame | 0.00000117 |
| run | 0.6 s | 2.6 m/s | 0.0000757 m | 0.0000435 m/frame | 0.00000149 |

Walk uses a four-beat sequence and weight shift; run uses a faster diagonal running trot with suspension. Idle includes breathing, head/ear movement and tail sway. No charge, attack, recovery, hit or death animation has been added.

Exported deformation was independently re-imported into a fresh Blender session and compared to the source at every keyed frame. Godot's imported skin was compared independently at every frame of all three clips. All comparisons passed the 0.0001 matrix tolerance. Loop endpoints match, root translation is zero and IK leg lengths are preserved. The editable source and runtime are separate by design; Godot does not require Blender IK constraints.

The isolated Godot import disables animation optimization/compression and immutable-track removal, retaining subtle breathing and exact reference playback. Import precision settings are in the included `.glb.import` file. See [Godot advanced import settings](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_3d_scenes/advanced_import_settings.html).

## Body surface patch correction

The reported patches were visible surface openings, not a color redesign. Imported UV boundaries had coincident geometry with independent weights. The former reduction also simplified disconnected boundaries independently, leaving unmatched seam edges. The derivative is now connected at a 0.00001 m weld distance before reduction, with original per-corner UVs retained. Its normal map was rebaked against the unchanged approved high-resolution source. Weight diffusion operates on a shared physical graph; both low and high skins synchronize coincident positions.

The original diagnosis measured up to 0.310 m seam separation at a sampled run pose. The corrected regression checks every keyed pose:

| Clip | Keyed poses checked | Maximum coincident-position separation |
|---|---:|---:|
| idle | 121 | 0.00000000 m |
| walk | 37 | 0.00000000 m |
| run | 19 | 0.00000000 m |

The source model, colors, rig, clip timing and motion remain preserved. New recordings replace the previous patchy recordings. `repair_surface_seams.py` records the derivative-only topology repair; `prepare_stage_a.py` now includes the same weld before future reductions. The patch correction adds no runtime materials, shaders or effects.

The optimized Blender surface has 0 boundary edges, 0 loose edges and 0 nonmanifold edges. Its UVs are per-corner, so it has no duplicate geometric seam vertices. Godot recreates 28,237 duplicate render vertices for UV/normal splits; these were independently checked and the maximum corresponding skin-weight difference is 0.0. Thus the imported seams retain identical transforms throughout playback. Original material culling is retained; no two-sided material override hides gaps. The complete animation reference JSON matches the approved version exactly.

## Performance and remaining limits

- Original: 1,917,784 triangles / 1,023,627 vertices. Export derivative: 120,000 triangles / 59,964 Blender vertices. Godot reports 88,201 render vertices after UV/normal splits. This is approximately 93.7% fewer triangles.
- One material, unchanged 4K base color, locally baked packed 2K tangent normal, four skin weights and 30 runtime joints. No hair simulation or expensive runtime fur system.
- This is a review LOD, not a measured mobile performance guarantee. Physical-device profiling, lower LODs, texture-memory tuning and encounter-scale approval remain for integration. The current source does not contain a separate physically based roughness or emissive map; none is invented to change its approved colors.
- Surface details follow the supplied generated mesh. The static source's dense irregular topology is not a hand-retopologized deformation cage. Extreme future combat poses may require additional local weight or topology work.
- The run is a running trot, not a cinematic gallop. Charge motion is intentionally reserved for Stage B.
- Some local surface stretching remains at inner limb attachments during locomotion; the measured outlier counts above are retained for visual review. This is not presented as an approved final commercial animation set.
- The local Godot headless editor emitted a safe-save warning; asset import, independent runtime verification and actual rendered playback completed successfully. Runtime verification had no errors. No antivirus/security setting was changed.
- No phone FPS, GPU-memory benchmark or gameplay combat test is claimed for this isolated Stage A asset.
