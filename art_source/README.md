# Demon Boar checkpoint

This checkpoint contains the approved Demon Boar source, Stage A rig and
locomotion, and the corrected body surface seams. It is an art review asset;
the creature has not been integrated into gameplay or enemy AI.

## Approved files

- Original supplied model: `phase3_1/demon_boar/tripo_import_01/demon_Boar.glb`
- Editable rig: `phase3_2/demon_boar/stage_a/demon_boar_stage_a.blend`
- Runtime export: `phase3_2/demon_boar/stage_a/demon_boar_stage_a.glb`
- Actual animation previews: `phase3_2/demon_boar/stage_a/previews/`
- Isolated Godot review project: `phase3_2/demon_boar/stage_a/godot_stage_a_review.zip`
- Production report: `phase3_2/demon_boar/stage_a/STAGE_A_REVIEW.md`
- Asset credit: `phase3_2/demon_boar/stage_a/ASSET_CREDIT.md`

Blender automation, original texture extraction, verification results and the
delivery hash manifest accompany the asset. Binary art files use Git LFS.
Install Git LFS before cloning/checking out this checkpoint's binary assets.

Working Blender snapshots, superseded procedural revisions, `.validation`,
engine caches and APK builds are excluded. Ignoring snapshots does not delete
them. Stage B combat animations are not included in this checkpoint.

The `.gdignore` files keep art sources outside Godot's live game imports.
Extract the review ZIP into its own directory to inspect the isolated project.
