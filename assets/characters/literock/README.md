# Dire Wolf Lite (local licensed dependency)

Creator: Literock Studios / Literock Ventures.
Source: https://literock-studios.itch.io/direwolf-lite
Version: 1.0.0, retrieved 2026-11-05.

Download the free archive from the source and place `Dire_Wolf_Lite.glb` in this
folder, then let Godot import it. The standalone GLB is deliberately gitignored:
the creator permits commercial games and modification but prohibits re-uploading
or redistributing the standalone asset. Packaged distribution in our game is
allowed. Keep the creator's bundled license with your local download.

9,991 triangles, 35-bone rig, 2K PBR textures; idle, walk, run and bite clips.
Creator discloses Meshy-generated base mesh/textures with custom rigging and
animation work. Credit: Dire Wolf by Literock Studios.

The game uses one source model for three size/tint variants, not three distinct
species. No geometry or textures from Beast Quest are used. The older procedural
creatures are a development fallback if the local GLB is absent; Godot logs a
warning. Install the GLB before acceptance testing or building the intended art.
