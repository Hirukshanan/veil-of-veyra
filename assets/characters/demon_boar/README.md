# Demon Boar runtime asset

3D model generated by Logachandran Hirukshanan using Tripo3D.

`demon_boar.glb` is the unchanged approved Phase 3.2 Stage B export. Its editable
source, production scripts, original source attribution and verification are in
`art_source/phase3_2/demon_boar/stage_b/`. This runtime copy is imported by Godot;
the art-source folders remain excluded from the game's importer.

Eight clips: idle, walk, run, charge_warning, charge_attack, charge_recovery,
hit_reaction and death. Thirty runtime joints, four skin influences, one material,
120,000 triangles. Original packed 4K color and 2K normal are preserved.

The `.glb.import` retains exact animation sampling and configured loop flags.
Keep it alongside the GLB. Godot regenerates platform-specific imported resources.

Generation attribution is separate from the owner's applicable Tripo account
usage rights; the existing asset credit and source provenance remain authoritative.
