# Samsung A37 combined candidate test

Approval is pending. After approval, update the existing Island Test app in place using the included APK. Do not uninstall, clear app data, or use the production app. If installing via ADB: `adb install -r APK/Veil_of_Vera_Task54_720p_Candidate.apk`. This command was not run on a phone during this task.

1. Record phone model, Android version, RAM, battery %, ambient temperature and whether charging. Begin with the saved 30 FPS/shadows-off baseline; retain a copy of existing test saves through the prior approved local profiling workflow.
2. Check the lower primary controls with each thumb, Kick and Special reach, center visibility and display cutouts. If an old customized profile exists, inspect the new defaults in Customize HUD; reset that layout only if you choose to, then Save.
3. Walk normally without leaving the stick ring: no accidental sprint. Drag upward beyond the upper rim and hold until SPRINT appears; release to stop. Drag farther and hold for AUTO; release, then touch the stick again to cancel. Verify stamina, combat interruption, pause and background/resume cancellation.
4. On empty gameplay space, spread two fingers for closer view, pinch for farther. Confirm 4–9m bounds and cave/rock camera collision. Repeat while holding joystick and tapping sword with two additional fingers. No accidental attack, orbit jump or stuck movement should occur.
5. Open Settings. Swipe card titles/empty areas to scroll. Touch only slider tracks to adjust values. Test all three tabs, Customize HUD, Back, Reset preview and Save. Restart the test app and confirm camera, volume, control size, shadows and frame limit retain their selected values. Confirm campaign/test save progression also remains intact.
6. Repeat Task 5.1/5.2 forest, hills, mountains, river entry/escape, cave, coast and connections. Repeat Task 5.3 wolf pursuit and at least five avoidable boar charges, interrupted obstacle charges, escape and death checks. Do not change normal health to make this pass.
7. Follow the existing Task 5 profiling kit for sustained 20–30 minute sessions and local frame/counter CSVs. Record FPS/frame-time spikes, memory, battery delta and actual measured temperature/thermal status when available; otherwise mark unavailable. Compare like-for-like quality and record any charging/background load differences. Try 60 FPS only as an optional setting, not an accepted target.
8. Return screenshots/feedback and local profiler output privately. Do not upload device logs to third-party services. Production map activation remains a separate approval.
